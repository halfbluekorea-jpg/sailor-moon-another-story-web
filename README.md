# 세일러문 Another Story · 한국어 웹 플레이어

PC와 휴대폰 브라우저에서 실행하는 개인용 SNES 플레이어입니다. 게임 ROM은 포함하지 않습니다.

## 플레이
1. 페이지를 열고 본인이 가진 일본어 원본 ROM(.sfc/.smc)을 선택합니다.
2. 한국어 초안 또는 일본어 원작을 선택하고 **게임 불러오기 → 원작 게임 시작**을 누릅니다.
3. 화면 버튼, 터치, 키보드로 조작합니다. 소리 크기는 오른쪽에서 조절합니다.

ROM은 브라우저 메모리에서만 읽습니다. 한국어 선택 시 IPS 패치를 브라우저에서 적용하며 원본 파일을 수정하거나 서버로 전송하지 않습니다. 변형된 ROM은 자동 검증에서 거부합니다. 512바이트 복사기 헤더는 자동 제거합니다.

지원 원본 SHA-256: `b85f5970ea619b7a6671a4de8cce430e2654a2e5bbef5e74ef35d4702dadb67b`

## 조작 및 저장
- 방향키: 이동 / Z: 확인 / X: 취소 / A: 메뉴 / S: Y / Enter: 시작 / Shift: Select / Q,E: L,R
- 화면 아래 게임패드: 마우스 및 멀티터치. 게임 화면을 누르면 대화 확인.
- 브라우저 저장 슬롯 3개. **백업 내려받기**로 저장 파일을 보관합니다.
- 기존 로컬 사이트의 저장은 자동 공유되지 않습니다. 기존 페이지에서 백업을 내려받고 새 페이지에서 **백업 불러오기**로 옮기세요.
- 휴대폰으로 옮길 때 원본 ROM과 저장 백업 파일을 해당 기기에 준비해야 합니다.

## 한글화 범위
스토리 3,391개 항목(원문 14,127줄), 메뉴 14종, 아이템·기술 설명·프로필에 한국어 초안을 적용합니다. 처음 208줄은 직접 번역했고 나머지는 로컬 번역 모델로 작성했습니다. 오역이 남아 있을 수 있으며 전투창과 일부 이미지 글자는 일본어입니다.

## GitHub Pages 배포
저장소 Settings → Pages → Deploy from a branch → main / (root) → Save. `.nojekyll`을 포함한 정적 파일만 배포하며 별도 API 키나 서버가 필요하지 않습니다.

로컬 확인: 이 폴더에서 `python -m http.server 8773` 후 `http://localhost:8773/`에 접속합니다. 파일을 직접 더블클릭하는 방식은 지원하지 않습니다.

## 구성 요소
EmulatorJS 4.2.3 / Snes9x. 해당 저작권 및 라이선스는 `third-party/`에 보관합니다. 세일러문 및 원작 게임의 권리는 각 권리자에게 있으며 이 프로젝트는 비공식 팬 플레이어입니다.
