# 세일러문 Another Story · 한국어 웹 플레이어

[게임 시작](https://halfbluekorea-jpg.github.io/sailor-moon-another-story-web/)

PC와 휴대폰에서 페이지를 열고 **게임 시작**을 누르면 한글판을 실행합니다. ROM 선택이나 별도 API 키가 필요하지 않습니다. 첫 실행 때 게임과 에뮬레이터를 내려받으므로 잠시 기다려 주세요.

방향키: 이동 / Z: 확인 / X: 취소 / A: 메뉴 / S: Y / Enter: 시작 / Shift: Select / Q,E: L,R. 화면 아래 버튼은 마우스와 멀티터치를 지원합니다. 게임 화면을 누르면 대화를 진행합니다. 소리가 들리지 않으면 게임 화면을 한 번 누르고 소리 크기를 확인하세요.

저장 슬롯 3개와 JSON 백업을 지원합니다. 저장은 브라우저·기기별로 보관되며 이전 사이트의 백업도 불러올 수 있습니다.

스토리 3,391개 항목(원문 14,127줄), 메뉴·아이템·기술 설명·프로필의 한국어 초안입니다. 오역이 남아 있을 수 있고 전투창과 일부 이미지 글자는 일본어입니다.

사용자 승인으로 한글판 실행 파일을 포함합니다. 세일러문과 원작 게임의 권리는 각 권리자에게 있으며 비공식 팬 플레이어입니다. EmulatorJS 4.2.3과 Snes9x 라이선스는 third-party/에 있습니다.

GitHub Pages는 main 브랜치의 루트에서 배포합니다.
